# 第一章 基本组成与控制对象

## 1. 能量转换链

进气系统 → 压气机 → 燃烧室 → 透平 → 发电机。

压气机消耗透平输出的一部分功率：

P_透平 = P_压气机 + P_发电机 + P_损耗

## 2. 主要控制变量

- 转速 N：启动、并网前调速、超速保护。
- 有功功率 P：并网后负荷控制。
- 排气温度：热负荷限制与保护。
- 燃料流量：机械功率和燃烧热输入。
- IGV 角度：空气流量、温度和压气机工况。
- 压力、流量、振动、润滑油参数：监测和保护。

## 3. 核心认识

并网前燃料主要影响转速；并网后燃料主要影响有功功率。控制系统负责正常调节，保护系统负责危险状态下停机。
