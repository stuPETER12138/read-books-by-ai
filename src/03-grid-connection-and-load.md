# 第三章 并网与负荷控制

## 1. 并网条件

发电机与电网应满足：电压相近、频率相近、相位角接近、相序一致。

同步转速：

n_s = 60f / p

其中 p 为极对数。

## 2. 并网后负荷控制

功率给定 P* 与实际功率 P 比较，负荷控制器调节燃料，使 P 跟踪 P*。

负荷变化率限制：

|dP/dt| ≤ R_P

## 3. 多重限制

W_f = min(W_负荷, W_温度, W_加速度, W_排放)

## 4. 调频

一次调频由本地调速器根据频率偏差快速响应；二次调频由 AGC 或调度系统重新分配功率并恢复目标。
