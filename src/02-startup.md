# 第二章 启动控制

## 1. 启动阶段

启动许可 → 预润滑 → 启动装置拖动 → 达到点火转速 → 点火 → 火焰确认 → 继续升速 → 自持转速 → 退出启动装置 → 额定转速。

## 2. 关键概念

- 点火转速：允许投入燃料并点火的最低转速。
- 自持转速：透平功率足以克服压气机、附件和损耗，机组能自行加速。
- 启动许可：润滑油、燃料、启动装置、断路器、进排气和无跳闸条件均满足。

## 3. 点火失败

规定时间内无火焰：关闭燃料、退出点火、盘车吹扫、锁存故障；未经吹扫不得再次投入燃料。

## 4. 启动保护

超速、超温、加速失败、启动时间过长、火焰丧失、振动异常等均可能导致停机。
