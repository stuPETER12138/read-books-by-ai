# 第四章 温度控制与热保护

## 1. 温度测量

透平入口温度过高且分布不均，工程上常用排气温度阵列间接反映热状态。可计算平均值、最高值和温度偏差：

ΔT_spread = T_max - T_min

## 2. 温度基准

温度基准随转速、负荷、环境温度、环境压力和 IGV 等变化：

T_base = f(N, P, T_amb, P_amb, IGV, ...)

## 3. 控制与保护

温度控制是连续限制燃料；温度保护是在超限后快速跳闸。通常：

T_control < T_trip

## 4. 故障处理

单点异常应做冗余比较、中值选择或异常剔除；保护逻辑不可为了避免跳闸而随意屏蔽高温信号。
