# 《燃气轮机发电机组控制系统》学习资料

本文件夹按章节整理课程内容，建议按 01→20 顺序学习。

## 学习方法
1. 先读章节目标和核心概念。
2. 对照控制框图理解信号流向。
3. 记录公式和关键变量。
4. 完成章节练习，再进行综合复习。
5. 实际机组的阈值、逻辑和阀位方向必须以制造商手册、现场规程为准。
